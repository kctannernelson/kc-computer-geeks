# KC Computer Geeks Website

A static website for KC Computer Geeks designed to run on GitHub Pages.

## Files

- `index.html` — website content and layout
- `style.css` — responsive dark-theme styling
- `script.js` — mobile navigation and contact form email generation

## Publish with GitHub Pages

1. Create a new GitHub repository such as `kc-computer-geeks`.
2. Upload `index.html`, `style.css`, and `script.js` to the root of the repository.
3. Commit the files to the `main` branch.
4. Open the repository's **Settings**.
5. Open **Pages**.
6. Under **Build and deployment**, select **Deploy from a branch**.
7. Select the `main` branch and `/ (root)` folder.
8. Save.

GitHub will provide the Pages URL after deployment.

## Customize

Search `index.html` for:

- `kccomputergeeks@gmail.com` to change the email address.
- The Facebook URL to change the social link.
- Service names and prices to update pricing.
- Kansas City wording to update the service area.

## Contact Form

This website is static and does not collect or store form submissions. The contact form creates a pre-filled email using the visitor's default email application.
